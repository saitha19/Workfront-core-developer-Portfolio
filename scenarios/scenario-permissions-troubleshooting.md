
# Scenario: User Cannot See a Project

## Problem
A user reports that they cannot view a project they should have access to.

## Analysis
Common causes include:
- Incorrect sharing settings
- Insufficient access level
- Missing group membership
- Layout template restrictions

## Solution
1. Verify the project’s sharing settings.
2. Confirm the user’s access level includes “View” or higher.
3. Check if the user belongs to the correct group.
4. Review layout template visibility rules.

## Best Practice
Always start with project sharing, as it is the most common root cause.
