# Requests
  Requests are the Primary way unplanned work comes into the system.

## Key Points
- Requests are often the starting point of how work comes into Workfront, so a Request = Work intake.
- Requests and Issues are the same object type.
- Requests / Issues live within projects and tasks.
- Requests can be converted into tasks or projects.
- Requests can be assigned / routed to individuals or Teams
