# Workfront Packages

  Workfront package refers to the set of features that an organzation has purchased. These packages are divided into three areas
  1. Workfront Workflow
  2. Workfront planning
  3. Workfront Automation and integration
- All the above packages are further divided into Select, Prime and Ultimate Packages
NOTE : An Organization can purchase one or more of these areas.

# Workfront Licenses
An Organization purchases a certain number of Licenses when it purchases Adobe Workfront. As a system Administrator, you will use one of two types(plan & work) to assign to a user to access different workfront objects.
