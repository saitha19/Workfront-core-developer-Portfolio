
# Project Templates

Project templates standardize repeatable work and ensure consistency across teams.

## Key Elements
- **Task hierarchy** with durations and constraints
- **Predecessors** to control scheduling logic
- **Milestones** to track progress
- **Custom forms** to capture metadata
- **Approval workflows** for governance

## Example Template Structure
1. Intake & Requirements (Start ASAP)
2. Design Phase (Finish No Later Than)
3. Development (Fixed Dates)
4. QA & UAT (Must Start On)
5. Deployment (Start No Earlier Than)

Templates reduce setup time and enforce best practices across the organization.
